# Site deploy

These rules apply when publishing the built site. They do not apply to this guide repository.

## Identity

- Author and committer must be `Site <site@thailand-travelguide.com>`.
- Do not add `Co-authored-by` trailers.

## Message and title

- The commit message must be exactly `Update site`.
- The pull request title must be exactly `Update site`.
- The pull request body stays short and factual. Do not name repositories, handles, agents, tools, commit hashes, or workflow paths.

## Branch

- Use a short, neutral branch name (for example `publish` or `site-update`).
- Delete the branch after the pull request merges.

## Do not mention

In site commits, branch names, and pull requests, never mention:

- Repository names
- User or org handles
- Agent or tool names
- Commit hashes
- Workflow paths
