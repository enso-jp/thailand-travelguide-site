# Weekly SEO playbook

## Monday: inventory

- Export Search Console queries for 7 and 28 days.
- Mark queries that already have a page. Mark queries that need a district, route, or FAQ add.
- Priority order: visas and TDAC, when to go, Bangkok to Chiang Mai, Bangkok to Phuket, first week, south islands monsoon flip.

## Tuesday: one page, one lever

Change only one thing:

- Title and H1 alignment, or
- FactBar strings, or
- Two new FAQ pairs, or
- One new internal link from a hub, or
- One new `.aff-row` that matches intent (stay vs flight vs boat).

Do not rewrite the whole spine in one pass.

## Wednesday: money pages

Check click-out paths:

- Trip.com `stayLink` and `stayAreaLink` for the ten stay cities plus Ayutthaya.
- `flightLink` for BKK and DMK to HKT, CNX, USM, KBV.
- `trainLink` for Krung Thep Aphiwat to Chiang Mai.
- `transferLink` for BKK, DMK, HKT, CNX, USM.
- Klook tours, island hopping, tickets, rail and ferry via Travelpayouts marker 793638.

If a money page has no `.aff-row`, add one. If it has five, cut to the three that match the H1.

## Thursday: monsoon and freshness

- Recheck ferry language if you are in a shoulder month.
- Recheck TDAC and 60-day visa-free copy against official pages.
- Add a dated note only when a rule changed. Do not stamp every page with today's date.

## Friday: scoreboard

Against the $16.67/day network target:

- Sessions on `/plan/*`, `/get-there/*`, `/itineraries/*`, and the four Bangkok districts.
- Partner clicks and estimated EPC. If stays underperform, push district stay rows. If boats underperform, push Klook rows on Phuket, Krabi, and Samui only.

Write three lines in the weekly note: what moved, what you changed, what you will not touch next week.
